# Tofo Scuba — website MVP

One-page site for [Tofo Scuba](https://www.tofoscuba.com/), a PADI 5 Star Gold Palm dive resort on Tofo Beach, Mozambique.

- **Framework:** [Astro](https://astro.build) 5 (static output)
- **Icons:** Font Awesome 6 + [line-md](https://github.com/cyberalien/line-md) animated icons via `astro-icon`
- **Hosting:** Netlify (`netlify.toml`)

## Develop

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to dist/
```

## Editing content

All business content (prices, team, contact, image URLs) lives in `src/data/site.ts`.

## Easter eggs 🤿

Scroll to watch the depth gauge, click the hero for bubbles, type `manta`, `shark` or `bubbles`, try the Konami code, or click the logo 5 times.
